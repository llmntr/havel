# A-Frame VR Scene

A basic A-Frame scene configured for VR with a green ground plane and blue sky.

## Usage

1. Open `index.html` in a WebXR-compatible browser (e.g., Chrome, Edge, Firefox).
2. The scene will load with a green ground plane and blue sky.
3. To enter VR mode, click the VR button in the bottom right corner (if available) or use your VR headset.

## Requirements

- A WebXR-compatible browser.
- For VR experience, a VR headset connected to your computer.

## Troubleshooting

- If VR mode doesn't work, ensure your browser supports WebXR and your VR headset is properly connected.
- For local development, you may need to serve the files over HTTPS for WebXR to work in some browsers. Use a local server like `python -m http.server` or Live Server extension in VS Code.
